# Формат ефектів schema 2

Schema 2 описує **повністю новий ефект** даними (JSON), без жодного коду: як інтерфейс розбивається, коли кожен шматок
починає рух, які модулі його рухають і коли, як він виглядає, які частинки й звуки з'являються. Формат v1 («база +
параметри», `"schema": 1`) і вбудовані ефекти лишаються й працюють як раніше.

Готові приклади — у [`docs/examples`](examples): `mask_spiral` (спіраль на власній текстурі-масці), `mask_burn`
(горіння за маскою), `sprite_rain` (дощ із власних частинок), `layer_combo` (комбінація шарів).

## Де лежать ефекти

| Звідки | Шлях | Текстури |
|---|---|---|
| Тека конфігу | `config/shatter_gui/effects/<будь-що>.json` | `config/shatter_gui/textures/<ім'я>.png`, потім ресурспаки |
| Пакунок | `config/shatter_gui/packages/<будь-що>.shatterfx` | усередині пакунка, потім як вище |
| Ресурспак | `assets/<простір>/shatter_gui/effects/*.json` | `assets/<простір>/shatter_gui/textures/<ім'я>.png` |

- **Пакунок `.shatterfx`** — це ZIP: `effect.json` у корені і `textures/*.png`. Інші файли ігноруються. Перетягни
  пакунок у теку `packages` і натисни «Перезавантажити» у вкладці «Власні» редактора (або F3+T).
- Для однакового `id` пакунок важливіший за файл у `effects`, а той — за ресурспак.
- Ефекти перезавантажуються разом із ресурсами (F3+T) і кнопкою «Перезавантажити»; старі текстури при цьому звільняються.
- Ефект **без текстур** можна поділитися кодом-рядком (gzip + base64): «Експорт» на його картці, «Імпорт» у вкладці
  «Власні» (імпортований ефект записується як `config/shatter_gui/effects/<id>.json`). Ефект із текстурами
  поширюють пакунком.
- При першому запуску в `config/shatter_gui/packages` з'являється приклад `example_mask_spiral.shatterfx` (лише якщо теки
  ще не було).

## Перевірка й повідомлення

Кожне поле перевіряється. Повідомлення містять **шлях до поля**, наприклад
`layers[2].params.strength.keys[1]: times must go up (0.4 after 0.8)`.

- **Помилка** (неправильний тип, невідомий модуль/режим/easing, неправильний колір, ключові кадри не по порядку…) —
  ефект не завантажується; у лозі й у вкладці «Власні» видно перші помилки.
- **Попередження** — число поза діапазоном обрізається (`clamped`), невідоме поле ігнорується (`unknown field, ignored`),
  забагато елементів у списку — зайві відкидаються, невідома частинка чи звук — пропускаються, текстура не знайдена чи
  некоректна — функція, що її використовує, вимикається (маска фронту → шум, накладка → без неї, спрайт → емітер мовчить).

## Верхній рівень

```json
{
  "schema": 2,
  "id": "my_effect",
  "name": "My effect",
  "description": "Optional, shown in the editor.",
  "duration": 50,
  "fracture":  { },
  "trigger":   { },
  "layers":    [ ],
  "appearance": { },
  "emitters":  [ ],
  "sounds":    [ ],
  "modifiers": { "edge": { } }
}
```

| Поле | Тип | Обов'язкове | Опис |
|---|---|---|---|
| `schema` | число | так | Завжди `2`. |
| `id` | рядок | так | 1–32 символи `a-z`, `0-9`, `_`. Не може збігатися з вбудованим ефектом. |
| `name` | рядок | ні | Назва у списках (до 48 символів). |
| `description` | рядок | ні | Опис для редактора (до 200 символів). |
| `duration` | ціле | ні (40) | Тривалість усього ефекту в тіках, 2–400 (20 тіків = 1 с). |

### Модель часу

Ефект триває `duration` тіків. Кожен шматок починає рух у момент `trigger · spread · duration` (див. `trigger`) і далі
живе `duration · (1 − spread)` тіків. **Власний прогрес** шматка `p` іде від 0 до 1 за цей час; **глобальний прогрес** —
`час / duration`. Шари діють у вікні прогресу (`from`…`to`), а їхні криві обчислюються **всередині цього вікна** (0 на
початку вікна, 1 у кінці). Коли власний прогрес шматка доходить до 1, шматок зникає.

Налаштування мода діють і тут: «швидкість ефектів», «менше руху» (×0.65 тривалості, поштовхи ×0.5, обертання ×0.3)
і пресет змінюють тривалість; кількість частинок множиться на «кількість частинок», «менше руху» і пресет.

## Значення (`Value`)

Майже кожне число параметра може бути:

| Запис | Значення |
|---|---|
| `0.5` | стала |
| `{"value": 0.5, "jitter": 0.2}` | стала, для кожного шматка ×(1 ± 0.2) випадково |
| `{"random": [0.2, 0.6]}` | випадкове для кожного шматка в межах |
| `{"curve": "easeOutCubic", "from": 0, "to": 1}` | крива за часом (easing-пресет) |
| `{"bezier": [x1, y1, x2, y2], "from": 1, "to": 0}` | кубічний Безьє як у CSS `cubic-bezier` (x1, x2 у 0…1) |
| `{"keys": [[0, 0], [0.3, 1], [1, 0]], "ease": "smooth"}` | ключові кадри `[час, значення]` (час 0…1, зростає), між ними `ease` |

`jitter` (0…1) можна додати до будь-якої форми-об'єкта. Результат завжди обрізається до діапазону параметра.

**Easing:** `linear`, `easeIn`, `easeOut`, `easeInOut`, `easeInCubic`, `easeOutCubic`, `easeInOutCubic`, `easeInQuart`,
`easeOutQuart`, `easeInBack`, `easeOutBack`, `easeOutBounce`, `easeOutElastic`, `smooth`, `step`, `pulse` (0→1→0).

**Колір і градієнт:** `#RGB`, `#RRGGBB` або `#AARRGGBB`; градієнт — список кольорів (рівномірно) або точок
`[{"t": 0, "color": "#fff"}, {"t": 0.7, "color": "#a5f"}]` (до 16 точок, `t` зростає).

**Точка:** `"center"` (центр інтерфейсу), `"source"` (блок чи істота, з якої відкрили інтерфейс; без неї — як
`"player"`), `"player"` (точка перед гравцем), або `[u, v]` — частки інтерфейсу (u вправо, v вниз; можна трохи за межами,
−2…3).

## `fracture` — розбиття

| Поле | Діапазон (за замовч.) | Для режимів | Опис |
|---|---|---|---|
| `mode` | `grid`, `voronoi`, `strips`, `radial`, `pixels` (`grid`) | — | Як різати. |
| `count` | 1–1500 (60; radial 12) | усі, крім pixels | Приблизна кількість шматків (voronoi ≤ 320; radial — кількість секторів). |
| `cols`, `rows` | 0–64 (0) | grid | Точна сітка замість `count`. |
| `jitter` | 0–1 (0.35) | grid, voronoi, strips, radial | Наскільки нерівні межі. |
| `split` | так/ні (ні) | grid | Кожна клітинка — два трикутні шматки. |
| `direction` | `horizontal`/`vertical` | strips | Напрям смуг. |
| `segments` | 1–32 (1) | strips | На скільки частин ділиться кожна смуга. |
| `rings` | 1–12 (3) | radial | Кільця. |
| `center` | точка (центр) | radial | Центр (лише `[u, v]`, інакше центр). |
| `size` | 2–64 (8) | pixels | Сторона квадрата в пікселях інтерфейсу. |
| `region` | `[u0, v0, u1, v1]` | усі | Зона дії: так ріжеться лише вона; решта стає кількома великими шматками з групи `outside`. |

Шматок — одна або кілька трикутних частин, що рухаються разом (комірка Вороного, клітинка сітки…).

## `trigger` — фронт спрацювання

Коли кожен шматок починає рух: значення 0…1 на шматок → старт `значення · spread · duration`.

| Поле | За замовч. | Опис |
|---|---|---|
| `type` | `wave` | `none` (усі одразу), `wave` (уздовж напрямку), `radial` (від точки), `noise` (плями шуму), `mask` (яскравість текстури), `random`. |
| `direction` | `[0, -1]` | Для `wave`: напрям руху фронту в частках інтерфейсу (`[0, -1]` — знизу вгору). |
| `from` | `center` | Для `radial`: точка. |
| `scale` | 4 | Для `noise`: розмір плям (0.5–32). |
| `texture` | — | Для `mask`: маска (grayscale PNG; темне спрацьовує першим). |
| `invert` | ні | Для `mask`: світле першим. |
| `noise` | 0 | Скільки шуму додати до будь-якого фронту (рвані краї), 0–1. |
| `spread` | 0.5 | Частка тривалості, за яку фронт проходить, 0–0.95. |
| `curve` | `linear` | Easing, що застосовується до значення фронту. |

Маска з **власною текстурою** дає власний візерунок горіння чи розчинення: намалюй у PNG, де починати (чорне) і де
закінчувати (біле).

## `layers` — шари

До 16 шарів. Кожен — модуль, що діє на ціль протягом вікна часу.

```json
{ "target": {"group": "edge", "width": 0.2}, "module": "attract", "from": 0.3, "to": 1, "time": "local",
  "params": { "to": "player", "strength": 0.012, "swirl": -1.5 } }
```

| Поле | За замовч. | Опис |
|---|---|---|
| `module` | — | Обов'язковий, див. нижче. |
| `name` | — | Назва для редактора (до 32 символів); на ефект не впливає. |
| `enabled` | `true` | `false` — шар зберігається, але не грає («око» в редакторі). |
| `target` | `all` | Ціль: `"all"`, `"region"`, `"outside"` або об'єкт `{"group": …}`: `wave` (`from`, `to` — значення фронту), `edge` (`width` — відстань від краю, 0–0.5), `random` (`chance`, `seed`); `"invert": true` бере протилежне. |
| `from`, `to` | 0, 1 | Вікно прогресу. |
| `time` | `local` | `local` — власний прогрес шматка, `global` — прогрес усього ефекту. |
| `params` | — | Параметри модуля (числа — `Value`). |

Модулі (координати — у площині інтерфейсу: x праворуч, y вгору, z до камери; одиниці — блоки й тіки):

| Модуль | Параметри (діапазон, за замовч.) | Що робить |
|---|---|---|
| `stay` | — | Тримає шматок на місці (обнуляє швидкість і обертання). |
| `launch` | `from` точка (центр); `speed` 0–1 (0.08); `spread` 0–π рад (0.4); `out` −0.5…0.5 (0.02); `once` так/ні (так) | Поштовх від точки (з випадковим кутом); `out` — до камери. `once: false` — постійна сила. |
| `gravity` | `strength` −0.5…0.5 (0.04); `world` так/ні (так) | Прискорення вниз (у світі або в площині); від'ємне — вгору. |
| `drag` | `amount` 0–1 (0.05) | Гасить швидкість і обертання щотіку. |
| `attract` | `to` точка (центр); `strength` −0.5…0.5 (0.02); `swirl` −5…5 (0); `absorb` 0–1 (0) | Притягує до точки; `swirl` — закручування спіраллю; `absorb` — радіус (частка діагоналі), всередині якого шматок зменшується до нуля. |
| `drift` | `amount` 0–0.3 (0.01); `frequency` 0–2 (0.1); `out` 0–0.3 (0) | Плавний шум у русі. |
| `spin` | `speed` −2…2 (0.2); `tumble` −2…2 (0); `axis` 0–π рад (випадкова); `turn` −2π…2π рад (немає); `pivot` `[u, v]` (немає) | Обертання навколо нормалі й перекидання навколо осі в площині (рад/тік). `axis` — напрям осі перекидання від «праворуч» до «вгору» (π/2 — як картка навколо вертикалі). `turn` — точний кут перекидання за вікном шару замість швидкості `tumble` (картка стає ребром рівно на π/2). `pivot` — точка інтерфейсу (0..1 зліва й згори), через яку йде вісь, як петлі дверей: `[0, 0.5]` — лівий край. |
| `scale` | `value` 0–4 (1) | Розмір шматка (множники кількох шарів перемножуються). |
| `follow-path` | `points` до 8 точок `[x, y]` або `[x, y, z]` у ширинах інтерфейсу (x праворуч, y вниз, z до камери); `progress` 0–1 (smooth 0→1) | Рух уздовж плавної кривої (Catmull-Rom) від місця, де шматок був на початку вікна. |
| `collide` | `bounce` 0–1 (0.35); `friction` 0–1 (0.4); `rest` `lie`/`fade` (`lie`) | Зіткнення з блоками світу (той самий код, що в `glass`): шматок не проходить крізь блоки, відскакує з `bounce`, на землі втрачає `friction` бокової швидкості. Шматок, що зупинився, «засинає» (не перевіряється, поки його не штовхнуть); `rest: fade` — згасає за 10 тіків. Перевіряються лише шматки, швидші за 0.003 бл/тік; не більше 600 шматків хвилі; спільний бюджет 4000 перевірок блоків на тік (решта чекає наступного тіку). Без цього модуля шматки проходять крізь блоки, як раніше. |

## `appearance` — вигляд

| Поле | За замовч. | Опис |
|---|---|---|
| `color` | білий | Градієнт кольору (множиться на зображення). |
| `time` | `local` | Час градієнта кольору: `local` або `global`. |
| `alpha` | 1 → 0 в останні 25 % | Прозорість (`Value` за власним прогресом). |
| `emissive` | 0 | Сила світіння 0–1 (світиться без освітлення світу). |
| `emissiveColor` | як `color` | Градієнт кольору світіння. |
| `fullbright` | ні | Без затінення за нахилом. |
| `overlays` | — | До 4 накладених текстур, див. нижче. |
| `mask` | — | Маска вигляду: `{"texture", "threshold" (Value 0–1), "softness" 0.001–1 (0.1), "invert"}` — шматки, чия яскравість маски нижча за поріг, зникають (за центром шматка; для дрібного візерунка — режим `pixels`). |

Накладка (`overlays[]`):

| Поле | За замовч. | Опис |
|---|---|---|
| `texture` | — | PNG до 512×512. |
| `blend` | `normal` | `normal`, `additive` (світло додається), `multiply` (затемнює множенням). |
| `opacity` | 1 | `Value` за власним прогресом. |
| `color` | білий | Градієнт відтінку накладки. |
| `scroll` | `[0, 0]` | Прокручування UV за секунду. |
| `repeat` | `[1, 1]` | Скільки разів текстура вкладається по ширині й висоті інтерфейсу. |

## `emitters` — частинки

До 8. Кожен — **або** ванільна частинка `"particle": "minecraft:flame"` (лише прості частинки без параметрів), **або**
власний спрайт `"sprite": "<текстура>"` (PNG до 256×256, малюється власним рендерером білбордів, обличчям до камери).

| Поле | Діапазон (за замовч.) | Опис |
|---|---|---|
| `name`, `enabled` | — | Як у шарів: назва для редактора й «око». |
| `rate` | `Value` 0–50 (1) | Частинок за тік (крива за глобальним часом у вікні). |
| `burst` | 0–200 (0) | Разом на початку вікна. |
| `from`, `to` | 0–1 (0, 1) | Вікно глобального прогресу. |
| `zone` | `surface` | `surface` (на живих шматках), `edge` (по краю інтерфейсу), `front` (де щойно спрацював фронт), `point` (`at`), `line` (`lineFrom`–`lineTo`). |
| `velocity` | `[0, 0.02, 0]` | Початкова швидкість (x, y, z площини, блоки/тік, −1…1). |
| `spread` | `Value` 0–0.5 (0.01) | Випадкова добавка до швидкості. |
| `life` | `Value` 1–200 (20) | Тривалість життя (тіки). |
| `gravity` | −0.2…0.2 (0) | Прискорення вниз. |
| `drag` | 0–1 (0.02) | Гальмування. |
| `color` | білий | Градієнт за життям частинки (спрайти). |
| `size` | `Value` 0–1 (0.06) | Розмір у блоках за життям частинки. |
| `alpha` | 1 → 0 в останні 30 % | Прозорість за життям (спрайти). |
| `emissive` | так | Спрайт світиться (додається), інакше звичайна прозорість. |
| `max` | 1–400 (200) | Найбільше живих спрайтів цього емітера. |

## `sounds` — звуки

До 16: `{"sound": "minecraft:block.amethyst_block.chime", "volume": 0–1 (1), "pitch": 0.5–2 (1), "at": "start" | "end" | число 0–1}` (і, як у шарів, `name` та `enabled`).
Гучність множиться на загальну гучність мода.

## `modifiers.edge` — вхід/вихід через край

| Поле | За замовч. | Опис |
|---|---|---|
| `direction` | `random` | `left`, `right`, `top`, `bottom`, `random`. |
| `exit` | так | Наприкінці все відлітає за цей край. |
| `exitStart` | 0.4 | З якого глобального прогресу починається вихід. |
| `enter` | ні | На початку все прилітає з цього краю. |
| `enterTime` | 0.25 | Тривалість входу (частка ефекту). |
| `distance` | 1.3 | Відстань у розмірах інтерфейсу (0.1–4). |
| `curve` | `easeInCubic` | Easing виходу. |

## Текстури

- PNG; розмір перевіряється за заголовком **до** декодування: спрайти до 256×256, накладки й маски до 512×512.
- До 16 різних текстур на ефект (формат дозволяє назвати найбільше 14), файли разом до 2 МБ, не більше 64 текстур
  завантажено одночасно для всіх ефектів.
- Ім'я — без `.png`: `"spiral_mask"`; з простором імен — `"mypack:fx/spiral"` (лише з ресурспака). `..` у назві заборонено.
- Некоректний файл — попередження; текстури звільняються разом з ефектом (перезавантаження).

## Візуальний редактор

Усе описане вище можна робити без JSON — у редакторі ефектів (вкладка «Власні» в налаштуваннях мода або на весь
екран): шари з каталогу модулів, живий перегляд на зразку скрині/печі/інвентарю з перемоткою, таймлайн із вікнами
шарів і ключовими кадрами кривих, інспектор із людськими назвами й одиницями, редактор градієнтів, бібліотека
текстур, дизайнер частинок, вибір звуку з пошуком і прослуховуванням, галерея шаблонів, Undo/Redo (Ctrl+Z/Ctrl+Y),
Ctrl+S, пробіл — пауза. Редактор пише `effects/<id>.json` атомарно (тимчасовий файл і перейменування), експортує
пакунки в `config/shatter_gui/exports/<id>.shatterfx` і імпортує їх (з перевіркою, до запису; текстура з уже
зайнятою назвою зберігається під вільною, а посилання на неї в ефекті змінюються). Поле, яке редактор не знає,
лишається в JSON незмінним.

## Сумісність

- Двигун рахує все на процесорі по тіках, рендер інтерполює між тіками; власних шейдерів немає.
- **Spatial GUI**: рух іде в осях площини Spatial у світових координатах — ефект грає на 3D-екрані так само.
- **Шейдерпаки (Iris)**: уламки, накладки `normal`/`additive` і спрайти малюються ванільними типами, які шейдерпаки
  підтримують; `multiply` з шейдерпаком малюється як `normal` (власний конвеєр множення шейдерпак не освітлює).
- **Спам-захист**: як і для вбудованих — більше 4 хвиль одразу змушує найстаріші згаснути за 6 тіків, разом із їхніми
  частинками.
- Рядки профілю `[ShatterProfile] fx.<id>.fracture / .setup / .done` показують розбиття, підготовку й підсумок хвилі.
